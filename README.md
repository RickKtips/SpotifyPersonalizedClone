# Spotify personalized Clone

Projetão criado com [Angular CLI](https://github.com/angular/angular-cli), versão 16.2.16.
A ferramenta foi feita para testar o acesso as Apis do spotify, e funcionar como um clone do app original, com layout personalizado e personalizável, contem as funções básicas do player, e o sistema de playlists do usuario.

Dispõe tambem de sistema de login integrado obviamente, é um teste criado para re-lembrar toda a lógica do angular 16.


para rodar?

 `ng serve` 
 
 Depois navegue para `http://localhost:4200/`.
